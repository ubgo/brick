# Tooling guides

The tools around a theme: how to lay files out, edit them and test them.

| Guide | What it covers |
|---|---|
| [Formatting with `brick fmt`](fmt.md) | One layout for every `.html` file; `-l`, `-d`, `-w`, wrapping and attribute order; the same code as the editor's format request |
| [Editors: `brick lsp` and VS Code](editors.md) | Diagnostics, completion, hover, go to definition, rename and format in an editor |
| [Testing with bricktest](bricktest.md) | Drive a page in `go test`: submit, click, upload, effects, view log, golden files |
| [statetest](statetest.md) | The conformance suite for a custom state store, codec, sealer or key ring |

See also the [CLI reference](../../reference/cli.md).
