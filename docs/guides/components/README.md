# Components and templates

How to build pages out of components: what a component is, how values and markup reach it, where shared data comes from, how a component fetches its own data, how it carries CSS and browser code, and what happens when something breaks. Every page is built around a runnable program under `examples/components-*/` whose test checks the exact output the page shows.
