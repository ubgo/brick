Children are the message; an actions block adds a link or button after it. brick v2 is out. Maintenance on Sunday. We launched! Read more A dismissible banner needs an id: JavaScript shows the close button and remembers the dismissal in localStorage under "bk-banner:", so the banner stays gone on later visits. Change the id to show a new announcement to everyone again. Without JavaScript the close button stays hidden and the banner always shows. The bar is a region landmark named regionLabel ("Announcement"); give each banner on a page its own name (regionLabel="Maintenance notice"), so assistive technology can tell the landmarks apart. label names the close button. */}} // DISMISSED_PREFIX + the banner's id is the localStorage key that remembers // a dismissal; a banner without an id cannot be remembered. const DISMISSED_PREFIX = "bk-banner:"; brick.mount("Banner", (el) => { const key = el.id ? DISMISSED_PREFIX + el.id : ""; let gone = false; try { gone = key !== "" && localStorage.getItem(key) === "1"; } catch (e) {} if (gone) { el.hidden = true; return; } const btn = el.querySelector(".bk-banner__close"); if (!btn) return; btn.hidden = false; const dismiss = () => { el.hidden = true; if (key) { try { localStorage.setItem(key, "1"); } catch (e) {} } brick.emit("banner:dismiss", { id: el.id }); }; btn.addEventListener("click", dismiss); return () => btn.removeEventListener("click", dismiss); }) .bk-banner { --bk-banner-bg: var(--bk-primary); --bk-banner-fg: var(--bk-primary-fg); display: flex; align-items: center; justify-content: center;
