Pure CSS: it shows on :hover and on keyboard focus (:focus-visible), after delay milliseconds, placed on side. Where the browser has CSS anchor positioning the tip is fixed to the trigger, so an overflow: hidden ancestor cannot clip it and it flips at the viewport's edge; elsewhere it is positioned inside the wrapper. The tip is role="tooltip" and the wrapper points at it with aria-describedby; the client module moves that pointer onto the first focusable child, where a screen reader reads it, or makes the wrapper focusable when there is none, and lets Escape hide the tip (WCAG 1.4.13).
