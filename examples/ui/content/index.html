brick kit

A component library for brick: buttons, forms, overlays, data tables, charts and app layouts, rendered on the server in Go. Every component works without JavaScript and gets better with it.

Or import single components remotely and run brick vendor:

 2 · Lay out the page

class="bk-base" on <body> opts in to the base font, colours and focus rings. {{ "{{ assets }}" }} goes first in the body, so each component's CSS loads before the content that uses it, and <Theme /> carries the design tokens. The script in <head> applies a saved theme and accent before the first paint.

 3 · Use a component

A component is a tag. Attributes are props, <brick:prop> blocks carry markup, and anything else you write on the tag — id, aria-*, hx-* — lands on the component's root element.
