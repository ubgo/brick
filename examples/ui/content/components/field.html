How the id travels

A Field picks the control's id and provides it (with the hint and error ids, the invalid flag and required) to everything inside it. Every kit control injects that context, so the label's for, the control's id and its aria-describedby always match — you never write an id twice. Put one control in a Field; a list of checkboxes belongs in a Fieldset, and a RadioGroup names itself after the Field's label.
