ConfirmDialog

{{ .Params.description }}

One attribute: brick:confirm

For a plain "are you sure?" no wrapper is needed: brick:confirm="Clear the form?" on any element with brick:click, brick:submit, brick:change or brick:keydown asks first and sends nothing on Cancel. On a page that has a ConfirmDialog, like this one, that question opens this dialog (registered with brick.confirmWith) instead of the browser's confirm(); data-confirm-label names its button. Try Delete all in the first example. Pages without a ConfirmDialog keep the browser's dialog, as on the deferred form.
