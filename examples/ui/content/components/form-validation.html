How it works

  • State on the server. The component declares state:; brick:submit="save" on the form sends its named fields to the Starlark save action as one dict.
  • Errors for one render. save returns [state, errors] when something is wrong. Each <Field :error=".Errors.email"> shows its message, marks the control aria-invalid and links the message with aria-describedby. The typed values survive because they are saved in the state.
  • Loading. While the action runs, brick:loading shows the spinner and the submit button is disabled.
  • Success. A valid submit returns the state with saved = True, and the template renders the confirmation instead of the form.
  • No browser validation in the way. novalidate on the form lets the server be the one place rules live; drop it to get the browser's checks first as well.
