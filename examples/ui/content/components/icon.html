Adding an icon

Icons live in kit/data/icons.yaml, one line each: the name, then the d of every stroked path on a 24×24 grid. Copy the paths from Lucide, write circles and rectangles as paths, and keep the file alphabetical. The kit's lint test fails on any icon name a kit file uses that is not in the set.
