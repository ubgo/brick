How it works

The server renders every row, so without JavaScript this is the complete table and a surrounding <form> submits the ticked rows. The client module sorts by each cell's raw value (numbers as numbers, text in natural order), filters on the row's text, and shows one page at a time. Selection changes fire a bk-select DOM event with {keys}. For tables too large to send whole, page on the server with Table and Pagination.
