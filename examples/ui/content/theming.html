Dark mode

Dark mode follows the system. data-theme="dark" or data-theme="light" on <html> forces one, and ThemeToggle switches it and remembers the choice. Only colour tokens change between the two, so a component written with tokens gets dark mode for free.

Accents

data-accent on <html> swaps the primary colour for the whole page: indigo (the default), blue, emerald, rose, amber, violet or zinc. Try it — the AccentPicker below sets it and saves it, and every primary colour on this site follows.

Your own brand

Override tokens in a stylesheet loaded after <Theme />. Set the dark values under :root[data-theme=dark] (and, if you follow the system, inside @media (prefers-color-scheme: dark) too).

One section only

Tokens are inherited custom properties, so setting them on any element rethemes everything inside it — a rose danger zone, a squarer marketing block — and nothing outside.
